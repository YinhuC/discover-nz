# Fonts

Latin and latin-ext subsets of the variable fonts served by Google Fonts, self-hosted so visitors make no requests to Google.

| Playfair Display | `playfair-display-*.woff2` | Copyright 2017 The Playfair Display Project Authors (https://github.com/clauseggers/Playfair-Display), with Reserved Font Name "Playfair Display" | [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/) |

To refresh them, request the families from `fonts.googleapis.com/css2` with a current browser user agent and replace the latin and latin-ext files, keeping the `@font-face` rules in `src/index.css` in step.
